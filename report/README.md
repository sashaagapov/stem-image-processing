# Звіт

Сюди кладеться фінальний звіт (`.docx`) і допоміжні зображення
(`report/assets/`) — зображення до/після, таблиці й графіки метрик.

Структура звіту (за методичкою):

1. Анотація та ключові слова.
2. Вступ (актуальність, мета, огляд суміжних робіт — див. `docs/related_work.md`).
3. Опис вибірки зображень.
4. Опис методів/пайплайнів і обґрунтування вибору параметрів.
5. Лістинг ключових функцій (повний код — у Додатку); посилання на Git-репозиторій.
6. Результати: зображення до/після, таблиці й графіки метрик (з `results/metrics_summary.csv`),
   порівняння методів/пайплайнів (особисте й загальнокомандне).
7. Обговорення: інтерпретація результатів, обмеження методів.
8. Висновки та можливі напрямки подальшого дослідження чи публікації.
9. Список джерел (ДСТУ або APA).
