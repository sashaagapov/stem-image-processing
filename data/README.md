# Вибірка зображень

**Домен (чернетка, див. [TZ.md](../TZ.md)):** обличчя людей, датасет
[LFW — Labeled Faces in the Wild](http://vis-www.cs.umass.edu/lfw/).

## Як підготувати вибірку

1. Завантажити з офіційної сторінки LFW невеликий піднабір (достатньо
   10–30 фотографій для базового рівня; більше — лише якщо команда захоче
   піти на «просунутий»/«експертний» рівень, див. TZ.md).
2. Покласти 10–15 репрезентативних зображень у `data/samples/` — саме
   на них працюватиме `common/compare.py` і де лежить перша тестова вибірка
   для розробки/демо.
3. Якщо вибірка стане великою (≥100), решту класти в `data/full/` —
   ця папка вже в `.gitignore`, у репозиторій вона не йде. У звіті вказати,
   звідки взята вибірка та скільки зображень фактично використано.

## Формат

- JPG/PNG, будь-який розмір — пайплайни самі приводять зображення до
  потрібного вигляду на вході першої стадії за потреби.
- Імена файлів — без пробілів і кирилиці (напр. `sample_01.jpg`), щоб не
  було проблем з шляхами між macOS/Windows.

## Межові випадки для тестування (критерій C2)

Окремо варто мати в `data/samples/` (або окремій підпапці `edge_cases/`,
не обов'язково для щоденної розробки, але для фінальної перевірки):

- дуже маленьке зображення (напр. 3×3 — 5×5 px);
- монохромне (grayscale) зображення;
- файл із неправильним розширенням/пошкодженим вмістом (перевірка, що
  програма не падає, а дає зрозумілу помилку).
