# Огляд суміжних робіт

Потрібно щонайменше 5 суміжних наукових робіт із порівнянням підходів
(критерій C5, 0,25 ваги). Короткий огляд — не реферат; для кожної роботи
досить 3–5 речень: що робить, який метод, чим відрізняється від того, що
реалізовано в проєкті.

Формат джерел — за ДСТУ або APA (обрати один стандарт і дотримуватись
послідовно в усьому звіті).

## Шаблон запису

### [Короткий заголовок / тема роботи]

- **Джерело:** Автор(и), назва, рік, видання/конференція, DOI або посилання.
- **Що робить:** …
- **Метод:** …
- **Порівняння з нашим підходом:** чим відрізняється обраний у роботі
  метод від того, що реалізовано в пайплайні(ах) проєкту (ручна класична
  реалізація vs. їхній підхід) — сильні/слабкі сторони.
