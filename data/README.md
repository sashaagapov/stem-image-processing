# Вибірка зображень

**Домен (чернетка, див. [TZ.md](../TZ.md)):** супутникові/аерознімки
земної поверхні, датасет
[UC Merced Land Use Dataset](http://weegee.vision.ucmerced.edu/datasets/landuse.html)
— 21 клас землевикористання (ліс, річка, житлова/агро/портова
забудова, парковки тощо), 256×256 px, по 100 знімків на клас.

## Як підготувати вибірку

1. Завантажити архів з офіційної сторінки датасету (або дзеркало на
   Kaggle — пошук "UC Merced Land Use Dataset").
2. Обрати знімки з **кількох різних класів** (не з одного!) — щоб було
   видно різну текстуру/контури/кольори для аналізу й порівняння методів
   (це напряму підсилює критерій B2 і «розмір вибірки» в C5).
3. Покласти обрані зображення в `data/samples/` — саме на них працюватиме
   `common/compare.py`.

**Фактична вибірка проєкту:** 100 зображень (розширена вибірка, критерій
D1/C5), 6 класів UC Merced по 16–17 знімків: agricultural,
denseresidential, forest, harbor, parkinglot, river. Усі 100 — у
`data/samples/` (невеликий сумарний розмір, ~2,5 МБ, тож окрему
нетрековану `data/full/` не використовували).

## Формат

- JPG/PNG, будь-який розмір — пайплайни самі приводять зображення до
  потрібного вигляду на вході першої стадії за потреби.
- Імена файлів — без пробілів і кирилиці (напр. `sample_01.jpg`), щоб не
  було проблем з шляхами між macOS/Windows.

## Межові випадки для тестування (критерій C2)

Окремо варто мати в `data/samples/` (або окремій підпапці `edge_cases/`,
не обов'язково для щоденної розробки, але для фінальної перевірки):

- дуже маленьке зображення (напр. 3×3 — 5×5 px);
- монохромне (grayscale) зображення;
- файл із неправильним розширенням/пошкодженим вмістом (перевірка, що
  програма не падає, а дає зрозумілу помилку).
